## 90-second demo script

1. (10 s) Landing, then a click-to-walk to the dusty panel.
2. (20 s) Pick up a rock, run the experiment, switch on the radio.
3. (25 s) Storm warning: show the real event named in the message, run to the cellar, show the dose with and without shelter.
4. (20 s) Switch to Hard on Mars: a fast storm with a late warning.
5. (15 s) Debrief: chart, mission code, the NASA sources panel.
